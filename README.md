# qr_project

Quantitative equity research on cross-sectional linear models, training sample selection, and IC-based evaluation.

股票截面线性预测的阶段性量化研究，比较训练样本处理、标签变换、损失函数和正则化对每日 Pearson IC 的影响。仓库保存实验代码、配置、结果记录与研究报告。

## 当前成果

- 按全市场交易日历精确匹配未来价格，构造五日预测标签并屏蔽跨训练边界的标签。
- 实现 OLS、Ridge、Lasso、MAE、平滑残差 L0.5，以及按日标准化、日期等权和截面中心化实验。
- 完成 18 项实验，保留参数搜索、模型系数、逐日 IC 和结果汇总。
- 通过同训练样本对照，区分特征删减与样本保留的影响。

## 阶段性结果

训练期为 2012–2018 年，内部验证期为 2018 年；测试期为 2019–2020 年。当前结果使用共同五特征完整评价池，共 1,366,724 行、482 个有效交易日。

| 配置 | 训练行数 | 验证日均 IC | 测试日均 IC |
| --- | ---: | ---: | ---: |
| 五特征 OLS，删除缺失行 | 3,352,997 | 0.041747 | 0.012861 |
| 三特征 OLS，与基准使用相同训练行 | 3,352,997 | 0.041071 | 0.012845 |
| 五特征 OLS，仅训练波动率缺失填 0 | 3,638,573 | 0.042311 | 0.018384 |
| 五特征 Ridge，仅训练波动率缺失填 0 | 3,638,573 | 0.042583 | 0.018041 |

来源：[完整实验汇总](analysis/results/summary.csv)。控制训练样本后，三特征模型没有表现出独立优势；保留波动率缺失的训练记录在当前测试区间改善了 OLS 表现。验证与测试池不随训练填补而扩大。

这些结果属于阶段性探索。测试期结果已用于后续诊断，不能将整组探索视为预先冻结方案后的独立确认；后续仍需新的时间区间检验。已实现行为以当前代码、配置和报告为准。

## 运行

当前本地环境使用 Python 3.12。主实验依赖记录在 `requirements.txt`；依赖版本来自整理时的本地环境。

```bash
python -m venv .venv
# Windows PowerShell
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m analysis.analysis
```

macOS/Linux 使用 `.venv/bin/python` 替换上述 Python 路径。

运行前，将原始 CSV 放在 `基础数据/基础数据.csv`，或修改 `analysis/config.py` 中的 `DATA_PATH`。原始数据和原始课题文档保留在本地，不随仓库发布；重新训练需要自行取得数据。

CSV 需要以下列，五个特征沿用题目提供的预处理尺度：

```text
股票代码, 日期, 原始股价, 成交金额, 总市值, 换手率, 二十日波动率, 复盘后开盘价, 复权后收盘价
```

`复盘后开盘价` 是输入文件使用的实际列名。正式标签为 `C(t+5) / O(t+1) / 5`，不减 1；评价指标为每日截面 Pearson 相关系数的算术平均。

已有结果可直接浏览。缓存记录包含原始数据的本地路径、文件信息和代码指纹，换机器后通常需要重新计算，不保证直接命中旧缓存。

如需重建 PDF，先安装 `requirements-report.txt`。报告脚本位于 `output/pdf/`，使用本地字体及路径配置，跨平台运行前需检查这些配置；已生成的 PDF 可直接阅读。
